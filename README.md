# Digital Forensics Investigation Report

## Overview

This repository contains a sanitised digital forensics investigation report completed as part of an academic lab project. The project demonstrates evidence handling, forensic imaging, hash verification, artefact analysis, timeline reconstruction, and professional forensic report writing.

The investigation was conducted in a controlled environment using standard digital forensic tools and methodology.

## Project Objectives

- Preserve digital evidence using forensic best practices
- Create and verify forensic images
- Validate image integrity using cryptographic hashes
- Analyse documents, emails, images, metadata, and timeline artefacts
- Demonstrate chain of custody and evidence handling procedures
- Produce a professional digital forensic investigation report

## Key Skills Demonstrated

- Digital evidence preservation
- Forensic imaging
- E01 image verification
- Hash verification using MD5 and SHA-1
- Chain of custody documentation
- Search and seizure documentation
- File system analysis
- Metadata analysis
- Timeline reconstruction
- Artefact recovery
- Professional forensic reporting

## Tools Used

- FTK Imager
- Autopsy
- HashMyFiles
- Cryptii
- Windows forensic workflow
- Manual evidence documentation

## Main Areas Covered

- Evidence imaging exercise
- Single E01 image creation and verification
- Split E01 image creation and verification
- Write-blocker concept
- Search and seizure process
- Evidence labelling
- Artefact analysis
- Email, document, and image review
- Timeline analysis
- Final forensic conclusion
